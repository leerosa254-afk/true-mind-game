# 진짜 마음을 찾아라

중학교 3학년 사회정서교육을 위한 실시간 마음 토너먼트 웹앱입니다. 20명 이상의 학생이 참여 코드로 동시에 접속해 사회인식과 관계기술을 연습합니다.

## 주요 기능

- 캐릭터 모드, 친구 마음 모드, 혼합 모드
- 중3 생활을 반영한 24개 상황과 24개 감정
- 4강 감정 토너먼트와 실제 마음 공개
- 판단 단서 및 관계 반응 선택
- 10분·15분·25분 수업 프리셋
- 제출 현황, 10초 연장, 강제 진행, 중간 종료
- 친구 모드 익명 공개 및 `말하고 싶지 않아요` 원칙
- 모바일 반응형 화면과 재접속

## 로컬 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다.

## Render 설정

- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Auto-Deploy: On

## 권장 운영

15분 활동은 혼합 모드 3라운드(캐릭터 2회 + 친구 1회)를 권장합니다. 교사 1명이 방을 만들고 학생들은 참여 코드로 입장합니다.
